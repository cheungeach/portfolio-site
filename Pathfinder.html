Project · 01 · System Design

Pathfinder

A weekly job-search agent for students. Fewer, better, you decide. Every Monday it reads the postings, picks twenty, explains each pick with a reason tag, and drafts materials that cite the student's own stories — then the student chooses a mode per job: Skip, Focus, Assist or Managed.

Year2026
MediumNext.js · SQLite · Design System
DisciplineSystem Design · Product · UI
StatusRunnable, pipeline mocked
Principle

The agent proposes. The student decides. Nothing is sent that wasn't chosen, and nothing is written that isn't cited.

01 · Architecture

Five layers, one swap line

The UI never learns whether a report was produced by rules or by a model. Everything that will change lives behind three functions in lib/report.ts; everything that won't — accounts, schema, components — is built for real from day one.

03 · The Weekly Pipeline

From two hundred postings to twenty, each with a reason

01

Fetch

Pull ATS feeds and school packs; dedupe by org + title; drop past deadlines.

seedJobsIfEmpty()
02

Score

Base score plus a boost for matching the student's ranked directions; penalty for none.

base + max(0, 10 − 2·rank)
03

Tag

Four reasons, each with a one-line why: closes soon, strong match, big title, easy to get.

DL · MT · BT · EZ
04

Cite

Find up to two stories whose tags appear in the posting; they become the rationale's evidence.

storyIds: [3, 7]
05

Rank & cut

Deadlines within 7 days first, then score. Keep the quota.

.slice(0, quota)
06

Draft on demand

Materials are written only when a mode is chosen — one paragraph per cited story, one deliberately uncited.

04 · Modes & State

Four modes decide how much the agent does

A mode is set per job on the report. It is the only place where autonomy is granted, and it is granted one posting at a time.

Skip

Deletes any draft. The job stays in the report as declined so it isn't re-proposed.

Focus

The student writes; the agent supplies strategy, story chips and the posting's own words.

Assist

The agent drafts every paragraph with citations; the student edits and submits.

Managed · locked

Phase 3: Playwright submits on Greenhouse / Lever / Ashby. Shown with a lock so the boundary is visible now.
